# Cintelis Homebrew tap

```sh
brew install cintelis/tap/cintelis
```

Installs `cintelis`, **CISO AI - Hacker News**: a fast Hacker News reader for
the terminal. Source and releases: [cintelis/hackernews](https://github.com/cintelis/hackernews).

Update with `brew upgrade cintelis`.

The formula is generated by `scripts/brew-formula.sh` in cintelis/hackernews
when a release is signed: its checksums come from the release's
`checksums.txt` after that file's signature is verified against the Cintelis
release key (fingerprint `SHA256:RY9yd61LBZCa5WrzSkEet+1Dnt2zVu9zpMRbZMWIV+I`).
Don't edit it by hand.
